# Фикс

Прототип агента МТС Беларусь, который во время телефонного разговора сам фиксирует договорённости: задачу в CRM и событие в календаре. Пользователь — Алексей Морозов, продажи оргтехники. Абоненты белорусские: номера +375, суммы в белорусских рублях (Br). Интерфейс на русском. Это демонстрация, не боевая запись сети.

## Что показывает

- Исходящий звонок Марии Соколовой («Лучи», МФУ, +375 29) и входящий Олега Кима («Неман Логистик», принтеры, +375 33). Фразы вроде «пришлите КП до пятницы», «ответим в течение 3 дней» и суммы в белорусских рублях становятся карточками без нажатий.
- Подсказка: «Зафиксирована договорённость… Подтвердить?». Задача уже создана, подтверждение необязательно. Дату, сумму, текст и приоритет можно исправить — правка уходит в задачу и календарь.
- Абонент слышит, что разговор фиксируется. Пока нет согласия, на звонке горит ожидание.
- Напоминания по срокам на сегодня, завтра и по просрочке. Просроченное КП «Лучи» — пример потерянной сделки.
- Задачи, внутренний календарь с событиями на днях и кнопка «Скачать всё» (файл `.ics`), правила и приоритеты.
- Журнал: кто открыл расшифровку и что сервер записал.

Разбор фразы делает сервер, не зашитый список. На карточке клиента играет запись разговора. Свою запись положите в `public/inbox/` или замените файл в `public/recordings/` — подойдут `.wav`, `.mp3`, `.ogg`, `.m4a` и `.webm`. При следующем открытии речь и голоса разбираются локальным faster-whisper и сохраняются в карточке: задачи и календарь строятся уже по этому тексту. Демо-файлы Марии, Олега, Сергея и Натальи остаются со сценарием, пока сам файл не заменён. Аудио наружу не уходит. Точность заранее не обещается: её можно посчитать только после прогона и сверки с текстом.

Простыми словами для защиты: [отчёт](http://127.0.0.1:4312/report) ([Word](http://127.0.0.1:4312/otchet-fiks.docx)) и [презентация](http://127.0.0.1:4312/present). Презентация листается стрелками.

## Запуск

```bash
npm install
npm run dev
```

Приложение откроется на [http://127.0.0.1:4312](http://127.0.0.1:4312).

Распознавание записи — локальный Python, без платного API. Если его ещё нет:

```bash
python3 -m venv /tmp/whisper-venv
/tmp/whisper-venv/bin/pip install faster-whisper
```

Модель `medium` скачается при первой загрузке файла и занимает около 1,5 ГБ. Другой интерпретатор можно указать через `WHISPER_PYTHON`, другую модель — через `WHISPER_MODEL`.

Проверка эталона фраз:

```bash
npm run check:accuracy
```

Состояние пишется в `data/vault.bin`. Каталог `data/` в git не входит.
